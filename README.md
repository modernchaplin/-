# AI 역사 핵심 키워드 프로그램

1950년대부터 현재까지 AI 역사에서 중요한 사건과 키워드를 빠르게 확인할 수 있는 간단한 CLI 프로그램입니다.

## 실행 방법

```bash
python3 ai_history_timeline.py
```

실행 후 시작/종료 연도를 입력하면 해당 범위의 타임라인과 핵심 키워드가 출력됩니다.

## 포함된 주요 흐름

- 튜링 테스트, 다트머스 회의
- 퍼셉트론, ELIZA
- 1·2차 AI 겨울
- 전문가 시스템, 딥블루
- 딥러닝 재부상, AlexNet
- 알파고, 트랜스포머
- 대규모 언어모델, 생성형 AI 대중화, 멀티모달/에이전트
